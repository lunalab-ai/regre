# 부록6.A · SAS 흐름을 R로 읽기

주교재279–283쪽의 SAS 예를, 이번 R환경에서 수행하는 작업과 대응합니다. SAS를 새로 설치하거나 실행하는 실습은 아닙니다. SAS 코드와 R 코드의 기본 범주 코딩은 다를 수 있어, 기준을 맞추고 같은 예측·제약을 비교합니다.

| 교재 SAS 작업 | R에서의 같은 역할 | 확인할 점 |
|---|---|---|
| `PROC IMPORT`, `DBMS=TAB` | `read.delim(..., header=TRUE)` | 구분자·열명·행 수·차량명의 공백 |
| `DATA`, 조건별 지시변수 | `as.integer(condition)`, 기준을 정한 `factor` | 결측을 숨기거나 행을 자동 삭제하지 않음 |
| 예측변수의 곱 만들기 | `X:Group` 또는 `X*Group` | `*`는 두 주효과와 곱항을 함께 포함 |
| `PROC REG`, `MODEL` | `lm(formula, data, na.action=na.fail)` | 실제 모형행렬과 계수 수 |
| 계수 제약의 공동 검정 | 같은 행의 `anova(reduced, full)` | 중첩·q·완전모형df |
| `OUTPUT ... P=`, 잔차 저장 | `fitted(fit)`, `residuals(fit)` | 관측과 평균 예측 구별 |
| `STUDENT` 표준화 잔차 | `rstandard(fit)` | 내부 표준화. 삭제학생화 `rstudent`와 구별 |
| 산점도·잔차 그림 | `plot`, `abline`, `qqnorm` | 축·집단·원자료 단위 유지 |

§6.2급료·§6.3상호작용·§6.4집단 비교는 이전 수업의 R경로를 유지합니다. §6.6계절·§6.7안정성은 이번 함수 본문에서 같은 절차를 수행합니다. 교재 스캔 전체나 장말 완성 답안은 학생 자료에 포함하지 않습니다.
