# W11A · 한 장 개념 지도와 기호 카드

## 기억할 네 질문

1. 범주의 숫자는 양인가, 이름표인가?
2. 한 사람의 0/1을 넣으면 어떤 항이 남는가?
3. 집단 차이는 높이 차이인가, 기울기 차이인가?
4. 같은 사람에서 어떤 제약을 풀어 비교하는가?

## 기호와 역할

| 기호 | 뜻 | 먼저 확인할 것 |
|---|---|---|
| E1·E2 | 학력 지시변수 | 기준은 대학원, 해당 집단이면 1 |
| M·Z | 두 집단의 0/1 표시 | 어느 집단이 0이고 1인가 |
| $\gamma$ | 두 집단 절편 차이 | X=0의 뜻과 관측 지지 범위 |
| $\delta$ | 두 집단 기울기 차이 | XZ 곱항이 있는가 |
| SSE | 잔차 제곱의 합 | 같은 반응값·같은 행인가 |
| k | 절편 포함 추정 계수 수 | 원래 변수 개수와 다름 |
| q | 완전모형에서 추가한 계수 수 | 두 설계공간이 중첩되는가 |
| $n-k_F$ | 완전모형 잔차 자유도 | 어느 모형이 완전모형인가 |

## 두 상호작용을 구별하기

급료조사 `X+Education*M`은 경력 기울기가 공통입니다. 두 집단 사례 `TEST*RACE`는 집단별 TEST 기울기 차이를 허용합니다. 기준만 바꾸면 같은 적합값, 항을 더하거나 제약하면 다른 평균모형입니다.

## R 계산 경로

`model.matrix` → `qr`·`qr.coef` → 설계행렬×계수 → 관측−적합 → 잔차²의 합 → 같은 행의 부분 F

모형식의 `*`는 주효과+곱항, `:`는 곱항입니다. `source()`는 정의를 읽고, `lm()`은 자료로 계수를 적합합니다. 준비 셀을 실행했다고 연습이나 해석을 완료한 것은 아닙니다.
