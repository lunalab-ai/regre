  id=c("A","B","C","D","E"),
  shift=c("AM","PM","AM","AM","AM"),
  minutes=c(20,25,NA,30,25)
)
keep <- !is.na(d$minutes) &
        d$shift == "AM" & d$minutes <= 25
selected <- d[keep, c("id","minutes"), drop=FALSE]

② `selected`는 2행 2열이며, 남는 id는 A와 B이다.

③ `selected`는 2행 3열이며, 원래의 모든 열이 유지된다.

```r

print(SSE_wrong)
```

② `sum(e_wrong^2)`로 계산하면 올바른 SSE인 6을 얻는다.

③ `SSE_wrong`이 0이므로 이 회귀선은 세 관측값을 모두 정확히 맞힌다.

④ `e <- y - yhat`으로 바꾸면 부호는 반대가 되지만 `sum(e^2)`의 값은 변하지 않는다.

**객관식 · 5점**

d <- data.frame(x=1:5, y=c(4,5,8,9,9))
fit <- lm(y~x, data=d)
new <- data.frame(x=3)
CI <- predict(fit, newdata=new,
              interval="confidence", level=.95)
PI <- predict(fit, newdata=new,
              interval="prediction", level=.95)
print(round(CI,3))
print(round(PI,3))
```

PI 출력

1   7 3.882 10.118
```

④ CI에서 PI로 옵션을 바꾸면 회귀계수를 다시 적합하므로 평균선의 기울기도 바뀐다.

## Q19 · 결정계수 계산 코드 수정

같은 관측 자료에 절편을 포함한 회귀모형을 최소제곱으로 적합하여 다음 **합성 요약값**을 얻었다. SST는 평균을 기준으로 한 총제곱합, SSR은 회귀제곱합, SSE는 잔차제곱합이다. 아래 코드는 실행되지만 보통 결정계수 $R^2$를 구하는 목적과 다르다. (가) 원래 식이 어떤 비율을 계산했는지 한 구절로 설명하고, `R2 <-`의 오른쪽 식을 수정하시오. (나) 원래 코드의 출력과 수정 후의 출력을 각각 구하시오. (다) 올바른 $R^2$의 의미를 한 문장으로 쓰시오. 풀이 박스에 식과 수치 대입 과정을 쓰시오.

SST <- 100
SSR <- 64
SSE <- 36
R2 <- 1 - SSR/SST
print(R2)

## Q20 · 설계행렬의 크기와 세 점예측

**단답형 · 5점**

설명변수 두 개를 갖는 **합성 자료** 세 행에서, 주어진 계수는 절편 10, $x_1$의 계수 2, $x_2$의 계수 $-1$이다. 모든 변수는 이 문제의 점수 단위를 사용한다. `cbind`는 열을 나란히 묶고 `%*%`는 행렬 곱이며, `dim`은 행 수와 열 수를 반환한다. 아래 코드에서는 `b`의 세 원소를 $X$의 열 순서와 같게 제공했다. (가) `X`와 `pred`의 크기를 각각 행×열로 쓰시오. (나) `pred`의 세 점예측을 행 순서대로 쓰시오. (다) `X` 첫 열의 1이 하는 일을 한 문장으로 설명하시오. 풀이 박스에 행별 곱셈·합 또는 이를 설명한 주석 코드를 쓰시오.

```r
x1 <- c(1,2,3)
x2 <- c(2,1,4)
X <- cbind(Intercept=1, x1=x1, x2=x2)
b <- c(Intercept=10, x1=2, x2=-1)
pred <- X %*% b
print(dim(X))
print(dim(pred))
print(pred)
```

### 평가 기준 - 합계 5점

| 평가 항목 | 인정 조건·부분점수 | 배점 |
|---|---|---:|
| 입력 행렬 크기 | X의 차원을 식별함. | 1점 |
| 예측 결과 구조 | 결과의 크기·자료형을 식별함. | 1점 |
| 세 예측값 | 각 0.5점. 식이 맞고 산술만 틀리면 해당 값 0.25점. | 1.5점 |
| 절편 열의 역할 | 열의 역할을 설명함(명칭만 쓰면 0.5점). | 1.5점 |

계산 과정이 전혀 없으면 문항 0점. 최소 한 행의 내적 전개와 나머지 행에 같은 원리를 적용한 과정 또는 수치 대입 코드를 보입니다. 동일 계수 부호 오독으로 일관 계산했다면 세 예측값 항목은 최대 1점입니다.
