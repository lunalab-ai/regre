# W10B data and helper provenance

- hand-five-w10b.csv: original teaching construction; 5 rows, arbitrary x/y units.
- nyrivers-w10b.csv: same official RABE6 NYRivers20 rows; Nitrogen original scale, ComIndl land-use percent. Physical nitrogen unit was not verified.
- scottish-hills-w10b.csv: same official RABE6 Scottish.Hills35 rows; Time seconds, Distance miles, Climb total ascent feet. Row23 Time2859. Do not replace with MASS::hills.
- Official companion: https://www1.aucegypt.edu/faculty/hadi/RABE6/ ; Korean main textbook2024, sections5.8–5.15.
- diagnostics-base/influence/effects-w10b.R are unchanged copies of their src definitions, with unique file names so other browser lessons keep their resource bytes.
- diagnostics-w10b.R contains inspectable numerical traces, not exercise answer lookups. Raw textbook scans are excluded.
