# W09B · 공개 수업용 숫자 자료

- nyrivers-w09b.csv: Ali S. Hadi의 [6판 공식 NYRivers 파일](https://www1.aucegypt.edu/faculty/hadi/RABE6/Data6/NYRivers.txt) 20행의 숫자와 강 이름을 유지했습니다. 탭을 CSV로 변환하고 열 이름·행 순서를 보존했습니다. Nitrogen은 공식 농도 척도, 토지이용 변수는 공식 비율 척도입니다. 이 차시 검토 파일에 없는 물리 단위를 새로 지정하지 않습니다.
- scottish-hills-w09b.csv: [6판 공식 Scottish.Hills 파일](https://www1.aucegypt.edu/faculty/hadi/RABE6/Data6/Scottish.Hills.txt) 35행. 공백 정리·CSV 변환과 첫 열 이름 Race 외에 수치를 바꾸지 않았습니다. Time 초, Distance 마일, Climb 고도 상승량 피트입니다. 23행 시간2859초를 유지합니다. MASS 자료의 분 단위 및 해당 행 값 차이를 구별합니다.
- hand-six-w09b.csv: 이번 수업을 위해 추가 구성한 6행 교육용 자료. 임의 단위이며 실제 조사로 해석하지 않습니다.

공식 사이트에서 제공한 숫자 자료를 출처를 밝혀 수업 계산에 사용합니다. 원 교재 스캔·출판사 편집 파일이나 확인하지 않은 CC 이용허락 표시는 포함하지 않습니다. 원 다운로드 바이트의 SHA-256과 검토 범위는 비공개 출처 기록에 보존됩니다. 숫자·이름·행 순서 보존을 실제 검사했습니다.
